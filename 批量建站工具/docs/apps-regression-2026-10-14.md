## 修复内容与使用方式

- 安卓采用 WorkbenchFileChooser 兼容层，为声明文档格式的控件以通用类型打开系统文件选择器，避免 Android/文件提供者的 RAR MIME 映射差异隐藏文件；选择后的格式、内容仍交给原有解析器验证，媒体拍摄流程保留。此修复依据上传声明和 Capacitor 映射代码，尚未取得小米真机文件选择结果。
- 普通建站可直接上传完整 RAR / ZIP / 7Z，或点击“选择解压后的数据源文件夹”。单独 JSON 不授予旁边图片的读取权限；选择文件夹才会连同配套图片导入。
- 批量建站可连续添加不同数据源文件夹，已有站点、广告分配和配置得到保留，至少两份数据源后继续。多份有效 JSON 要求明确选择，不静默猜测。
- 新目录适配器递归读取授权目录，按所选 JSON 的位置解析 ../assets 等图片引用，再复用原有规范化、图片命名、字段映射和生成器。
- 多 JSON 提示窗可用返回键／Escape 取消，取消保留已导入数据；Tab 留在选择窗内，关闭后焦点回到上传按钮。返回键的共享 JS 路径由真实 Windows 应用 API 验证，Android 硬件返回仍待真机。
