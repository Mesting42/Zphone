## 修复与保留决定

| 发现 | 处理 |
| --- | --- |
| 通用玻璃子元素规则把标签栏改回 relative | 共用样式明确设置 sticky、顶部位置、背景和层级。资讯、游戏及差异化配置面板均使用该规则。 |
| 模板高优先级规则覆盖人工卡片配置 | 新增独立 `js/configuration-controls.js`，记录人工微调，为预览和导出生成同一组限定于内容卡的 CSS；覆盖圆角、边框、内边距、图片高度、间距、列数、列表视图及分类标题调整。广告节点不属于该覆盖范围。 |
| 部分模板值未列入下拉框，显示“请选择” | 动态提供“跟随模板（当前值）”，同时同步原生 select 和自定义下拉按钮。 |
| 新版卡片动效没有读取“过渡时间” | 动效读取经过校验的时长，并通过 CSS 变量应用于指针交互；合法的模板中间值也有效。减少动态效果设置继续优先。 |
| 普通资讯详情按钮预览使用占位链接 | 预览与导出共用真实网址渲染；补齐资讯和游戏的“操作按钮链接字段”，按实际数据提供候选。图片 URL 不作为文章来源入口，游戏保留包内 HTML 路径支持。无有效地址的条目不显示虚假按钮。 |
| Hero、按钮或图片关闭后，相关样式看似无效 | 保留这些有用途的功能，按前置条件禁用并说明原因；开启对应结构项后恢复使用。 |
| 带框 Logo 的较小导航高度被自动提高 | 对资讯端现有最小 72px 规则增加说明。 |
| 选择新模板后残留旧人工覆盖 | 在模板切换及游戏随机模板入口清除旧覆盖标记。 |
| 游戏开关文字未关联输入控件 | 补齐 Hero、操作按钮及关于页面标签关联；资讯端同步补齐相关标签。 |

旧“卡片悬停”和“入场动画”入口已由共享动效系统隐藏、替代。本次保留其已有配置读取兼容性，不重新暴露第二套无效的动画入口。其余品牌、导航、页脚、分类、卡片字段、详情元信息、正文渲染、相关推荐、通用页面及差异化参数的事件绑定和生成器使用路径已按组核查。
