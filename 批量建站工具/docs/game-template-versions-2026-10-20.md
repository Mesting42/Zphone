## 后续维护与边界

后续运行 `npm run templates:build` 或 `npm run build` 会同步生成旧版渲染文件和内容哈希 URL；
不要直接修改生成文件或来源快照。兼容调整应放在版本接入模块。

本次验证针对本地网页版及其 ZIP 导出，不代表已安装应用已更新。
源游戏、外部链接和广告账户的线上状态不属于此次模板迁移的验证范围。
