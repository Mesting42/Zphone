## 原因与修复

八套模板原本无条件为首分类首卡启用跨栏及大图样式。默认两篇时，部分模板排成一张跨栏卡加一张普通卡，部分模板形成宽窄不等的两张卡。

`template-system/reference-presentation.js` 集中提供首页数量规则和 `leadCardSelector()`。八个 `templates/*/home.js` 模块使用该选择器，让首卡跨栏、图文方向、图片高度及标题大小仅在 5/7 篇时一起启用。首分类默认两篇使用普通卡片。平板内容网格使用两列，440px 及以下保持单列。

桌面（769px 及以上）的既有编排规则：

| 文章篇数 | 每行卡片数 |
| --- | --- |
| 1 | 1 |
| 2 | 2 |
| 3 | 3 |
| 4 | 2 + 2 |
| 5 | 1 + 2 + 2 |
| 6 | 3 + 3 |
| 7 | 1 + 2 + 2 + 2 |

上述规则只作用于首页文章网格；广告节点仍由生成器按原配置输出。修改模板源码后运行 `npm run templates:build` 更新 `js/template-packages.js`，不要手改生成文件。
