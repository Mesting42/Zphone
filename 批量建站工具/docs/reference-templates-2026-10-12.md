## 维护职责

`template-system/registry.js` 同时兼容 v1 和 v2；`reference-presentation.js` 负责品牌锁定组合、章节标题、连续图片/标题的阅读顺序与共同重排。模板不解析广告，不改变广告位置、开关、恢复或 GA。生成器仅在 CSS、导航、页脚、页面呈现四处调用可选适配；未选独立包时委托原输出。

原固定列数卡片使用 Flex 最大宽度，v2 网格显式清除这项最大宽度。首页 1–7 篇按实际文章数量编排，更多文章使用配置列数；首分类仅在 5/7 篇的布局中启用跨栏大卡。原阶段浏览器检查包含实际网格填充、长标题、放大文本、广告重叠与移动导航，后续定向检查的时间边界见上方修复记录。

修改包后运行 `npm run templates:build`。完整协议和目录结构见 `docs/template-packages.md`。正常构建会校验文件、协议、作用域与 CSS 语法，成功后才更新生成脚本。
