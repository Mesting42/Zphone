# 1.0.6.4 发布说明

发布日期：2026-10-13。版本标识：`1.0.6.4`；Git 标签：`v1.0.6.4`。

## 工作目录与发布范围

- 唯一应用工作目录及预览启动目录：`D:\Min\建站工具\批量建站工具`；Git 根：`D:\Min\建站工具`。沿用用户后续指定的原目录。
- 发布分支：`main`；本地预览端口：`5174`。
- 发布内容为当前应用自 `v1.0.6.3` 后积累的源码、模板、资源和维护文档；其他项目的未提交删除、本地研究缓存、交接草稿和测试素材不纳入发布提交。

## 主要改动

1. 独立模板包、模板构建及创建命令，8 套跨领域完整参考模板，分类布局与编号控制，以及封面显示修复。
2. 共享站点动效、36 个带来源及许可证的彩色领域图标、可配置的动效颜色与速度，以及减少动态效果适配。
3. 导航选中状态、移动端及键盘交互、玻璃导航样式与配置区折叠行为完善。
4. 字段匹配与各工作流导出摘要、按钮、进度反馈升级；批量广告策略上传区域增加进度条上方间距。
5. 配置导航吸顶；人工卡片配置在模板、预览及导出中一致生效；修复下拉值空白、过渡时间和模板切换残留状态，补齐操作按钮链接字段及配置前置条件说明。
6. 异步处理、图片缓存及 ZIP 导出改进，本地 FileSaver 依赖，以及广告恢复和原位置保留检查完善。
