# SiteFoundry 1.1.1

日期：2026-10-21，Asia/Shanghai；发布准备与全量回归于2026-10-20完成。

本版把尚未推送的离线工作台、原生应用源码和新旧模板接入整合到同一份源码发布。游戏建站、资讯普通及批量建站可分别使用新版或原工具旧版模板，保留各自随机搭配、会话配置恢复和广告接入路径。共享预览支持本地字体、嵌套 CSS、动态 JSON 资源及文件夹数据源导入。另修复工作台装饰层造成的手机横向溢出。

版本顺序为 `1.0.0 → … → 1.0.9 → 1.1.0 → 1.1.1`。历史标签对应关系见[版本映射](version-numbering-2026-10-20.md)；本次保留全部原提交历史。产品编号与广告脚本版本相互独立。

## 验证

版本元数据调整前已完成同一份冻结源码的网页全量回归，排除资讯与游戏的差异化精品建站：613项单元测试、540组广告运行补充验证、17份真实广告TXT、新旧模板与混合批量导出、83个ZIP/92个站点、6511个HTML及135062个本地引用检查通过。详细范围及原站自带的两项问题见本地完整报告 `docs/web-full-regression-2026-10-20.md`（不随源码仓库分发）。该报告保留测试时1.0.1的版本身份，不改写历史证据。

本次发布准备仅调整版本元数据与文档，没有在全量回归之后更改建站或广告业务逻辑。971份冻结源码与资源的哈希对比显示，仅主应用package.json和package-lock.json因版本号调整而变化。发布前生产构建通过，追加53项网页相关测试、6项Windows单元测试及5项构建运行时测试全部通过。Vite仍提示部分产物超过500kB；该提示未阻断构建。具体结果保存在本机 `coverage/release-1.1.1-20261020`。
