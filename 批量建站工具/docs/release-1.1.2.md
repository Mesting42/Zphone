# SiteFoundry 1.1.2

日期：2026-10-21，Asia/Shanghai。

新增“广告模板复用”工作流。上传已经加过广告的静态源码包后，实时预览保留原站布局与视觉；使用 JSON/图片 ZIP 或另一份静态站 ZIP 替换内容，并选择现有主题配色、上传新广告 TXT。首页卡片、完整详情正文、图片和相关链接一同更新；详情页数量随新内容变化，多余旧内容页被移除。

模板的导航、页脚、法律页、关于/联系页和原有排版结构继续保留。广告默认保留原位置与开关，可选择原站版本或任一内置 ad.js 版本。新 TXT 的域名可以与原模板不同，输出使用新 TXT 域名；该规则仅用于模板复用，其他工作流沿用已有严格配对。

修复了复用过程中仅替换标题而保留旧动态卡片、正文不完整、图片别名残留以及同名图片冲突的问题；内容解析、资源映射、模板重建和广告策略适配拆分为独立模块。未知动态页面结构在上传检查阶段提示不支持直接复用。本版支持纯静态源码包，未增加 React/Vite/Next 工程构建复用。

## 验证

最后一次业务源码修复后，在同一份冻结生产构建上重跑除差异化精品建站外的全部原有工作流及新增工作流：625 项单元、540 组广告运行、40 组响应式/动效界面状态均通过。真实输出的 85 个 ZIP、94 个站点、6617 个 HTML 页面和 137818 处本地引用检查无缺失；32 个原始测试文件及其测试副本哈希一致。

新功能覆盖 6 个真实原站模板，每个替换为 48 篇内容和 48 张图片；每个模板的 6 种 ad.js 选择均通过广告引擎与导出预检。JSON/图片 ZIP 和静态站 ZIP 两种内容来源均完成浏览器实际下载；320/375/390/768/1440 像素下无新增横向溢出或破图。完整测试产物与报告保留在本地 coverage，不随源码仓库分发。

美食原站在 390 像素下的 106 像素溢出，以及工艺原站详情页的 React 水合报错，在加广告前后均可复现；本版未修改用户原始站点。单元测试首次启动遗漏 npm 路径，修正测试环境后完整重跑 625 项通过，原始记录继续保留。

版本准备阶段仅调整版本元数据与发布文档；1268 份已验收源码和构建文件的哈希核对未发现其他变化，业务代码及已有业务构建产物保持一致。发布前生产构建、50 项模板复用/广告/工作流/新旧模板测试、6 项 Windows 单元测试和 5 项构建运行时测试均通过。Vite 的大体积产物提示仍存在。
