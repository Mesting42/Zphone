# SiteFoundry 1.1.3

日期：2026-10-21，Asia/Shanghai。

“广告模板复用”支持生成游戏站。上传已经加过广告的静态源码包后，选择“游戏站”及现有游戏目录即可建站，无需另传数据源。可读取当前内置目录、内置源 1–5、开源本地游戏和当前浏览器已保存的目录；生成游戏卡片、详情和运行入口，本地封面、游戏文件及来源许可证随 ZIP 导出。

模板复用按上传源码保留分类名称、图标节点、顺序、样式和各分组原有卡片容量。新内容超出原模板容量时只追加到最后内容区；前面分类的内容节点保持原分段。公共适配支持 emoji、独立图标节点、SVG、图片及 CSS 图标，不依赖某个站点域名、文件名或固定分类。

广告默认保留原 DOM 位置、相邻内容、容器标签、class、样式、间距和尺寸。例如原模板某分类两张卡片后的广告，在替换内容后仍位于该分类两张卡片后。手动放置模式继续可用；用户调整某个广告后，仅覆盖其位置。无法可靠识别的动态结构或分类数量会明确提示。

内容导入支持 JSON、ZIP、RAR、7Z、TAR、TAR.GZ/TGZ。隔离预览完善 CSS、JavaScript、JSON、字体、图片和本地游戏页面的资源引用，以及不透明来源下的临时存储兼容；保持父级预览 iframe 的来源隔离。修复游戏文件和封面路径别名、JFIF 素材及本地资源打包，并完善成品站嵌入游戏页识别、吸顶导航广告锚点及一至五列响应式卡片行间广告放置。

游戏目录读取、游戏内容适配、模板分类与卡片布局、预览资源映射和广告位置适配拆分为共享模块，资讯与游戏复用同一套模板结构保留规则。

## 验证

发布前重新运行 10 个相关测试文件，207 项单元测试全部通过，覆盖模板分类与图标、内容增减、游戏目录、导入、广告恢复与策略、预览资源、游戏素材和模板版本。另有 6 项 Windows 单元测试、5 项构建运行时测试通过；六份 package/lock 清单、Windows 构建版本及文件名、Android 版本与更新号、当前版本文档和发布说明链接一致，依赖内容未变。

1.1.3 生产构建通过，离线资源检查覆盖 33 个字体家族、239 份字体文件。Vite 仍提示部分经典脚本不参与模块打包、运行时 URL 保留及部分产物超过 500 kB；这些提示未阻止构建。

此前同批功能已完成以下浏览器与实际导出验证，报告保留在本地 `coverage/template-reuse-layout`、`coverage/template-reuse-games` 和 `coverage/template-reuse-preview`：

- 用户上传的真实模板在 1280、768、390 像素下与原始预览对比；分类完整 HTML、广告相邻节点、容器样式、实际间距及占位尺寸保持一致。83 款新游戏下，原分组 `[2,6,6,6,6]` 保留前四组，最后一组扩展为 63。
- 四种图标结构与三种宽度组合，共 12 组通用布局检查；默认 ZIP 中分类及广告容器与原包一致，手动移动第二个广告到页脚前后，预览与 ZIP 均符合所选位置。
- 8 组隔离预览资源样本、3 组资讯内容复用场景、72 款开源本地游戏的详情与游戏文件及 MIT 许可证导出；已保存的本地目录导出后，游戏点击计分可用。

本次是相关功能专项验证，未重新执行 1.1.2 的全仓库回归。原生安装包、真实设备、第三方远程游戏服务、线上广告填充、GA 后台及账户状态未纳入本次验证。
