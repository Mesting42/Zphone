# SiteFoundry 1.1.4

2026-10-23，Asia/Shanghai。本版记录 2265f46 中的功能修复，并将各端源码版本统一升级至 1.1.4。

## 主要变化

- 模板复用支持通用主题配色适配、主视觉内容同步和摘要行数配置，默认跟随原模板；保留分类、布局、广告节点与详情正文。
- 首页及详情页封面对应数据源，包括正文容器外的封面节点。
- 游戏首页主视觉与首张卡片去重；保留完整游戏目录及详情关联，资讯站原有分配规则不变。
- 旧版游戏卡片摘要开关与行数联动，支持不显示、1～4 行和完整显示，修复手机端强制隐藏及配置回显。
- 修复 React 多阶段源码构建广告丢失、非 React Vite 源码输出识别、已知广告版本识别、RAR/7Z 游戏图片 MIME 和保存目录兼容问题。
- 清理历史测试素材，保留 Android/JDK/Gradle 工具链及外部入口。清理记录见 test-material-cleanup-audit-20261023.md。

## 验证范围

功能提交前完整单元测试 59 文件、834/834 通过，生产构建、游戏生成器 smoke 和副本一致性检查通过。

专项验证覆盖模板导出与桌面/手机重开、详情封面、游戏首页完整目录及摘要。最近清理后摘要验证：6 个配置选项，桌面/平板/手机预览与 6 份 ZIP 三宽度重开共 36 组通过，详情正文完整、工作台 pageerror 0。历史大体积测试证据已按用户要求删除，相关旧文档中的 coverage 链接可能失效，不应宣称可以直接重放全部历史验收。

本次版本元数据和文档另行执行一致性检查与生产构建；不将此前单元结果描述成升级后的全量重跑。未重新试玩全部第三方游戏，未验证线上广告填充、账户、原生设备或新安装包。
