# 参考站柔光玻璃导航样式

用户确认采用新增可选样式的方式，当前资讯建站工具的所有模板均可选择。应用唯一工作目录 `D:\Min\建站工具\批量建站工具`，Git 根 `D:\Min\建站工具`，分支 `main`；修改前已运行 `git rev-parse --show-toplevel`。预览端口 5174，从上述应用目录启动。本次没有提交或发布。

## 使用

在“配置网站 → 样式配置 → 导航栏样式”选择“柔光玻璃（参考站）”。默认值保持原逻辑；主动选择柔光玻璃后，切换模板或随机换模板会保留该选择。选择其它导航样式后恢复原模板默认值逻辑。

预览和导出的首页、列表、详情及通用页面使用相同导航样式入口。站名、Logo、栏目、链接与模板字体保留当前配置；复制的是参考站的玻璃材质、胶囊形状与响应式外边距，不复制参考品牌或文章。

## 代码边界

- `js/navbar-layout.js`：新增纯 CSS 输出 `softGlassCSS()`，材质与折叠、动画控制器解耦。
- `js/generator.js`：新样式类 `soft-glass`；仅选择该样式时，在模板 CSS 后追加材质，避免模板皮肤覆盖参考参数。
- `js/app.js`：模板应用时保留主动选择的柔光玻璃。
- `index.html`：增加样式选项；资源哈希由模板构建入口更新。

原菜单宽度适配、展开/收起动画、ARIA、关闭状态和广告位置继续由原模块处理。
