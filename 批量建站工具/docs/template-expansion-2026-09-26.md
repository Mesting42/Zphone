- `js/data.js` 定义领域识别词、类别、图标、品牌、配色与模板生成配置；`js/template-catalog.js` 定义各领域的文字语境与视觉方向。

普通建站、广告移植建站和批量建站加广告使用同一领域目录。成品站加广告沿用上传的站点源码。差异化建站和批量广告策略不扩充模板。

历史模板 ID 和配置保持兼容。新增模板通过横向图文卡、图文阵列、编号索引行、通栏交替、成对图文行、全景内容架等内容结构区分；独立游戏另有主机启动台、卡带陈列、关卡选择等 8 种布局。领域配色、字体、栏目用语与品牌名称分别配置。新增布局没有引入杂志、纸张或笔记视觉。

样式面板新增“显示分类标题图标”开关：默认开启，关闭后只显示标题文字。原图标值仍保存，切换模板、随机组装不会重置显隐偏好；预览与导出使用同一标题组件。

## 代码职责

- `js/template-catalog.js`：布局元数据、36 个领域的视觉与文字配置、模板默认值。旧模板定义仍在各自的 `data.js` 中。
- `js/template-layouts.js`：共享的内容容器、栏目标题、卡片编排、阅读页 CSS 和选择器缩略图。不读取或执行广告代码。
- 两套 `generator.js`：继续负责数据、广告配置、广告脚本与导出；调用共享布局模块生成内容部分。
- 两套 `app.js`：模板选择、图标开关与配置同步。新布局随机组装保留领域设计默认值。

每个导出站只包含所选布局的 CSS，未把整个模板库写入网站包。新增样式以 `body[data-template-layout]` 限定作用范围。

## 广告兼容边界

- `js/ad.js` 与 `game-builder/js/ad.js` 源文件未修改。
- 广告 ID 解析、内置版本选择、上传的自定义版本、固定广告位置继续走现有模块。
- 首页内容容器只负责排版，广告仍由生成器按原位置输出。
- 卡片间的广告独占完整网格行；320px 详情页内的广告外框扩展到可用宽度，保留 300px 广告容器。
- 同时修复回归中发现的手动位置遗漏：普通建站在存在卡片间广告时提前生成首页卡片，使容器在 GPT 初始化前已存在；游戏预览补充显示已保存的卡片间广告。
- 修复游戏压缩包运行时在 Vite 下以经典脚本加载动态导入的语法错误；入口改为模块，RAR/7z 仍按需加载。
