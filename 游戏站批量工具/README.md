# 游戏站批量建站工具

浏览器本地运行的游戏静态站生成工作台。现有普通建站和广告移植工作流保持不变；`1.0.1` 开发中的“差异化精品建站”用于上传一个独立游戏数据包，生成不依赖应用服务器的英文静态站。

## 差异化模式

- 每个 ZIP 独立读取领域、目标读者、范围、正式域名、联系邮箱、设计选择和来源记录；
- 每款游戏必须提供可用的 HTTPS 外链或本地 HTML 入口；
- 每款游戏必须有准确的控制说明、本地封面、来源以及许可/使用依据；
- 可选 6 个游戏构图家族，自动模式优先避免重复使用并生成确定性设计指纹；
- 输出包含首页、栏目、游戏详情、信任/法律页、404、robots、sitemap、审计报告与授权记录；
- 草稿允许保留阻断项，递审版和广告版必须通过全部硬门禁；广告版还要求已校验的真实广告代码。
- 实时预览支持全屏查看，在全屏内仍可切换桌面、平板和手机尺寸，按 `Esc` 退出。

数据结构见 [差异化精品建站数据包规范](docs/differentiated-site-package.md)。

## 验证

```bash
npm test
npm run check
```

自动检查只能发现已编码的结构、功能和质量风险，不能保证事实、版权、搜索排名或 AdSense 批准。
